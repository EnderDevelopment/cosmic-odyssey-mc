# Cosmic Odyssey

Cosmic Odyssey is a Minecraft plugin that adds rockets, space, planets, and useful items and blocks obtained from space resources. This plugin aims to enhance the Minecraft experience by introducing a new dimension and gameplay elements inspired by space exploration.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server to load the plugin.

## Use

1. Launch a rocket by using the `/ciao` command.
2. Explore new planets and collect space resources.
3. Craft new items and blocks using space resources.
